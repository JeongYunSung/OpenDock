# AI Agent Instructions

## Working Agreement

- Read the repository before editing.
- Prefer the smallest change that satisfies the task.
- Preserve existing architecture and naming conventions.
- Run the documented validation commands before reporting completion.
- Do not modify generated files unless the project documents that workflow.

## Validation

- Start with the commands in `README.md` if they exist.
- If the project has no validation docs, inspect package or build files before
  choosing commands.
- Report any command that could not be run.
