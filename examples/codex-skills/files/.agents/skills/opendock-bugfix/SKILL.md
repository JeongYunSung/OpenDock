# Bugfix Workflow

1. Reproduce or describe the failing behavior.
2. Locate the smallest ownership boundary that explains the bug.
3. Make a targeted fix.
4. Add or update a regression test.
5. Run the narrowest relevant validation command.
6. Report the root cause and verification result.
