# Claude Code Instructions

Use this workspace as a design-aware project.

- Read `DESIGN.md`, `DESIGN_SYSTEM.md`, and `UX_REVIEW.md` before proposing UI changes.
- Keep suggestions grounded in user goals and product constraints.
- Prefer component-level changes that can be implemented and reviewed.
- Flag accessibility and responsive layout risks explicitly.
- Do not invent brand rules when the project has not defined them.
