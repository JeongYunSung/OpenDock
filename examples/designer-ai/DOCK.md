# Designer AI

Set up an AI-ready workspace for UI, UX, and product design work.

This dock installs the common AI tooling baseline and adds design-specific
project guidance: design system rules, UX review checklists, Figma workflow
notes, and reusable prompts. It is intended for designers and design leads who
want Codex or another agent to review interface work without spending hours
writing project instructions first.

Use it when a project needs a shared design language, repeatable UX review, and
clear handoff expectations.
