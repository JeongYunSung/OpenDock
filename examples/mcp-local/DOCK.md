# MCP Local

Install safe MCP configuration examples for local AI tools.

This dock does not enable external tools automatically and does not store tokens.
It places reviewed example files under `.opendock/mcp` so a project can copy the
right template into Cursor, VS Code/Copilot, Claude Code, or Codex after review.

Use it when a team wants repeatable MCP setup references without silently
activating tools.
